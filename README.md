An interactive web-based platform for visualizing sorting and pathfinding algorithms through animated execution, performance metrics, and interactive graph construction.

## Features

### Sorting Visualizer

Visualize and compare:

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

The sorting module provides:

- Animated algorithm execution
- Adjustable visualization speed
- Step/comparison tracking
- Swap tracking
- Execution time measurement
- Time-complexity comparison
- Sorting history

### Pathfinding Visualizer

Build graphs interactively and visualize:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's Algorithm
- A* Search
- Bellman-Ford Algorithm

The graph module supports:

- Interactive node creation
- Interactive edge creation
- Directed and undirected graphs
- Weighted and unweighted graphs
- Path visualization
- Path-cost calculation
- Step tracking
- Negative-cycle detection using Bellman-Ford
